# 领域术语表 (Domain Glossary)

- **迟智 (Post-hoc Deliberation)**：非实时、不打扰交流现场，专门在群聊高潮结束、热度回落后的沉淀特性。
- **瞬时速率 (Instantaneous Rate / Current Rate)**：短滑动时间窗口（如 60 秒）内接收消息数折算成的「条/分钟」。
- **动态日常基线 (Adaptive Baseline Rate)**：反映该群日常闲聊闲置底噪的长期加权移动平均（EWMA）速率。
- **突发倍率 (Burst Ratio)**：当前瞬时速率与动态基线速率的比值。
- **平息观察期 (Quiescence Window)**：讨论高峰回落到基线后，必须持续保持常态的时间长度（如 300 秒），用以确认思维碰撞真正结束。
- **思维碰撞矩阵 (Debate Matrix)**：记录不同派系、不同发言者之间的观点交锋、论点论据、相互反驳的结构化网格。
- **llmwiki 条目**：符合本地持久化知识库标准规范的 Markdown 文档，具备状态、双链、论点和引用。
